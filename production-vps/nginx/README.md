# VPS Nginx Reverse Proxy

This service is the public HTTP/HTTPS entry point for the VPS. It terminates TLS
with certificates mounted from `../certification/` and proxies to services on
`http-global-network`.

## Files

| Path | Purpose |
| --- | --- |
| `compose.yml` | Nginx container, public ports, config/cert/static mounts, and networks. |
| `nginx/nginx.conf` | Main nginx configuration. |
| `nginx/sites-enabled/` | Active virtual hosts. |
| `nginx/disabled/` | Disabled historical virtual hosts kept for reference. |
| `nginx/my-patches/` | Manual patches applied after regenerating nginxconfig.io output. |
| `nginx/nginxconfig.io/` | Shared snippets generated by nginxconfig.io. |
| `nginx/conf.d/` | Additional nginx config snippets. |
| `nginx/htpasswd/` | Runtime auth files; ignored because htpasswd hashes are secret-like. |
| `logs/` | Runtime nginx logs; ignored. |

## Mounted certificate paths

The container expects these runtime files, all ignored by Git:

- `../certification/letsencrypt-cert/_.mikufancx.cyou.crt` mounted under
  `/etc/ssl/`.
- `../certification/letsencrypt-cert/_.mikufancx.cyou.key` mounted under
  `/etc/ssl/`.
- `../certification/dhparam.pem` mounted at `/etc/nginx/dhparam.pem`.

Nginx config tracks only paths to certificate files, never certificate contents
or private keys.

## Operations

List recipes:

```sh
just --justfile production-vps/nginx/justfile --list
```

Render Compose config or validate nginx syntax:

```sh
just --justfile production-vps/nginx/justfile config
just --justfile production-vps/nginx/justfile validate
```

Boot, stop, or reload nginx:

```sh
just --justfile production-vps/nginx/justfile boot
just --justfile production-vps/nginx/justfile down
just --justfile production-vps/nginx/justfile reload
```

Boot/down/reload recipes change live VPS containers.

## Config update workflow

1. Generate or edit nginx config under `nginx/`.
2. Preserve `nginx/my-patches/` and apply relevant patches manually.
3. Run the `validate` recipe on the VPS.
4. Reload nginx with the `reload` recipe after validation passes.

See `note.md` for historical reverse-proxy notes, including the Content Security
Policy decision and WSS fallback patterns.
